# City photos

Drop real photos here (e.g. `sandton.jpg`, `nairobi.jpg`, `lagos.jpg`,
`marrakech.jpg`, `cairo.jpg`, `dubai.jpg`) and set the matching `photo` field
in `src/components/landing/africa-showcase.tsx` to `/images/cities/<file>` —
the illustrated skyline for that city is swapped for the photo automatically.
